# video_game_sale_analysis
Capstone project to answer the question is there a statistically significant correlation between critic review scores and global video game sales.

## Description
This project explores the correlation between video game critic scores and global sales using correlation analysis and linear regression. The analysis compares results of the correlation with and without outliers to evaluate the strength and stability of the correlation. 

## Requirements
Python 3.12

## Dependencies
* pandas
* numpy
* matplotlib
* scipy

## Inputs
Video Game Sales Dataset (CSV) - see sources below to download dataset

## Outputs
* Cleaned dataset (with and without outliers)
* Correlation results
* Linear Regression results
* Scatter Plot with Regression Line

## Commands
* Create folder for project
* Download CSV file into folder
* Run all cells in Jupyter Notebook in order

## Sources
* This project uses video game data collected from Kaggle. The original source of the data comes from [LearnToViz](https://data.world/learn-to-viz/martevizanaltica202307).
